# NexoraShop

Современный адаптивный стартовый проект интернет-магазина на Next.js, React, TypeScript, Tailwind CSS и PostgreSQL/Prisma.

## Что реализовано

- Тёмный premium-интерфейс, адаптивная главная страница, категории, карточки и страницы товаров.
- Поиск по каталогу, базовые фильтры и сортировка.
- Корзина с localStorage, количество товаров, сумма и демонстрационный промокод `NEXORA10`.
- Оформление заказа с валидацией на сервере, пересчётом цен по базе данных и уменьшением остатков в транзакции.
- Регистрация/вход, хеширование паролей bcrypt, сессионная cookie `HttpOnly`, JWT HS256.
- Подписка на новости в PostgreSQL.
- Защищённый ролью ADMIN интерфейс просмотра заказов/товаров и изменения статусов заказов.
- Prisma-модели для пользователей, товаров, категорий, заказов, адресов, отзывов и промокодов.
- SEO metadata и Open Graph metadata.

## Важно перед реальным запуском

Это стартовый проект, а не готовая к приёму платежей production-система. Товары и цены в seed — демонстрационные данные, их нужно заменить на реальные. Не обещайте сроки доставки, гарантию или возврат до утверждения условий. Реальная оплата не подключена. Не публикуйте сайт с демонстрационным промокодом, пока не утвердите его условия.

Для production нужно добавить как минимум:
- проверенный платёжный провайдер и обработку подписанных webhooks;
- полноценный UI управления товарами/изображениями и object storage (например, S3-совместимое хранилище);
- UI истории заказов/адресов/избранного на аккаунте, отзывы с проверкой покупки;
- rate limiting, CSRF/origin policy, журналирование и мониторинг;
- тесты, резервное копирование PostgreSQL, email-подтверждение и восстановление пароля;
- проверку юридических требований страны продаж и публикацию реальных политик конфиденциальности/возврата.

## Установка

Требования: Node.js 20+, npm и доступная PostgreSQL.

1. Распакуйте проект и откройте терминал в папке `nexorashop`.
2. Установите зависимости:

   ```bash
   npm install
   ```

3. Создайте PostgreSQL базу данных `nexorashop`.
4. Скопируйте `.env.example` в `.env` и заполните `DATABASE_URL` и `AUTH_SECRET` (секрет не менее 32 символов):

   ```bash
   cp .env.example .env
   ```

   В Windows можно скопировать файл вручную как `.env`.

5. Создайте таблицы и добавьте демонстрационные товары:

   ```bash
   npx prisma generate
   npm run db:push
   npm run db:seed
   ```

6. Запустите локально:

   ```bash
   npm run dev
   ```

7. Откройте `http://localhost:3000`.

## Назначение администратора

По умолчанию все регистрации получают роль `CUSTOMER`. Сначала зарегистрируйте свой аккаунт, затем назначьте ему `ADMIN` в базе данных через доверенную административную консоль PostgreSQL, сверив email. Например:

```sql
UPDATE "User" SET role = 'ADMIN' WHERE email = 'ВАШ_РЕАЛЬНЫЙ_EMAIL';
```

Не создавайте публичную форму назначения роли администратора. После изменения роли выйдите и войдите заново. Панель находится на `/admin`.

## API

- `POST /api/auth/register` — регистрация.
- `POST /api/auth/login` — вход.
- `POST /api/auth/logout` — выход.
- `GET /api/products?q=...&category=...` — поиск товаров по БД.
- `POST /api/orders` — создание заказа; цена берётся из БД, а не из браузера.
- `POST /api/newsletter` — подписка на новости.
- `GET /api/admin/orders` — список заказов (ADMIN).
- `PATCH /api/admin/orders` — изменение статуса (ADMIN).
- `GET/POST /api/admin/products` — просмотр/добавление товаров (ADMIN).

## Размещение в интернете

1. Создайте PostgreSQL базу в управляемом сервисе (например, Neon или Supabase) и задайте `DATABASE_URL`.
2. Разместите репозиторий в GitHub.
3. Создайте проект в Vercel, импортируйте репозиторий и добавьте `DATABASE_URL` и `AUTH_SECRET` в Environment Variables.
4. Выполните миграцию схемы для production и заполните каталог реальными товарами.
5. Подключите собственный домен и проверьте HTTPS, cookies, формы, email-подтверждение и резервное копирование.

## Известные ограничения этой версии

- Главная страница использует локальный набор демонстрационных карточек для красивого первого запуска; серверный API каталога читает PostgreSQL. Синхронизируйте UI с API перед production.
- В интерфейсе есть формы входа/регистрации и серверная авторизация, но после перезагрузки UI пока не запрашивает профиль автоматически.
- Панель администратора позволяет просматривать товары/заказы и менять статусы, но добавление/редактирование товаров пока доступно через защищённый API, без полноценной формы.
- Выбор доставки/оплаты демонстрационный. Интеграция платёжного провайдера отсутствует.
- Фотографии загружаются по URL; прямой upload и хранение в object storage не включены.
- Фильтры размера/цвета и страница отзывов требуют дальнейшего расширения.
- Перед публикацией проведите code review и security testing; этот проект не заявляет прохождение аудита.
